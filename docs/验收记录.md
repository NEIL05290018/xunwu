## 尚需在用户电脑完成

拉取代码、配置 JDK 17、启动本机 MySQL、建库或备份升级旧库、填写本机 `.env` 后启动。云端数据库不会随 Git Pull 复制到本机。本轮未对公网部署、真实支付、短信、真实快递、生产规模压测作验证。
