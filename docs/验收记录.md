## 浏览器实际操作

实际以三个独立浏览器会话分别登录卖家、买家、管理员：

1. 卖家发布台灯，管理员审核通过。
2. 买家收藏、联系卖家并发送消息。
3. 买家选择快递和地址，生成订单并模拟付款。
4. 卖家填写物流信息发货，买家确认收货并发表文字评价。
5. 390px 手机宽度下注册新账号、发布并删除无历史商品、退出登录。
6. 桌面/手机首页与登录页截图；检查手机无横向溢出。

最终流程全部通过，未捕获 JavaScript pageerror。验证中发现并修复了导航重复刷新导致聊天输入可能被清空的问题。

截图：`docs/screenshots/`。可复现脚本：`scripts/browser-acceptance.py`，需 Python Playwright 与 Chromium，并在独立验收库设置 `ACCEPTANCE_USER_PASSWORD`、`ACCEPTANCE_ADMIN_PASSWORD`。该脚本会创建真实测试记录，勿对要保持不变的数据运行。可选 `ACCEPTANCE_URL` 默认 localhost:8080。
