# v3.0 → v4.0 逐文件修改说明

Java 缩写路径均位于 `src/main/java/com/example/demo/`。完整源码已提交 GitHub，通过 Pull 同步，不需要逐个复制代码。

| 文件 | 改动 | 验证 |
|---|---|---|
| build.gradle | 版本4.0.0；MyBatis Starter3.0.4；保留MySQL驱动/JDK17 | JDK17构建 |
| DemoApplication.java | @MapperScan 扫描 mapper 包 | Spring启动 |
| mapper/*Mapper.java | 十二表接口及 SchemaMapper | 映射与业务测试 |
| resources/mapper/*.xml | 显式resultMap、CRUD、动态查询、行锁、自增回填 | MyBatisMappingTests |
| repository/ProductRepository | 保留六方法，委托ProductMapper | 六方法测试 |
| repository/MarketRepository | 类型化Mapper依赖与只读聚合；删除反射SQL及副本写回 | 页面隐私测试 |
| service/CatalogService | 数据库动态查询、商品行锁、商品图片同事务 | CRUD/失败回滚 |
| service/TradeService | 下单/交付/退款/评价事务与行锁 | 并发抢单、退款、快照 |
| service/CommunityService | 保留真实发起者、双向会话去重、消息/举报SQL | 反向并发会话 |
| service/AccountService | 地址直接Mapper写入；保留组合响应隐私过滤 | 地址/隐私 |
| service/AuthService | 从Controller移出账号SQL与验证 | 注册登录 |
| controller/AuthController | 只处理HTTP及会话，调用AuthService | 会话/CSRF |
| model/User、Admin | 增加供Mapper读取的password_hash，@JsonIgnore防止输出 | 哈希不序列化 |
| DatabaseStartup、service/SeedService | 初次MyBatis事务种子、旧库结构检查 | 空库/已有库启动 |
| resources/application.properties | XML路径；自动读取根目录.env；删除元数据缓存特殊设置 | IDEA/脚本启动 |
| database/schema.sql、resources/db/schema.sql | 报告约束、会话真实发起者与技术唯一列 | 实际MySQL建表 |
| database/migrate-v3-to-v4.sql | 保留旧业务数据和密码的单次结构升级 | v3空白副本导入→升级 |
| database/insert-demo.sql、resources/demo-seed.json | 对齐上传的样例，移除旧字段及第13表，图片有效 | 手动/自动种子 |
| start.ps1、start.sh、release/ | 改用v4.0.0 JAR | 解压运行 |
| src/test、docs/test-results | 迁移原测试、增加MyBatis测试 | gradlew test |
| README、docs、完整交接文档 | 本地拉取、建库、连接、差异、教学路线 | 文档与源码核对 |

前端API保持兼容，页面功能保留。未做 MyBatis 之外的前端框架切换，也未添加学生模块。
