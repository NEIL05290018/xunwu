# 从上传的 v2.0 到 v3.0：改哪里、怎么验证

本项目包中的文件均为完整可替换源码。跨电脑升级请解压到独立目录，按 README 配置，不要只替换一个 Controller 或仅改版本号。上传包带有 .idea、.gradle、build；交付包排除这些机器相关内容。

| 文件/目录（相对项目根目录） | 改动 | 验证 |
|---|---|---|
| build.gradle | 版本 3.0.0，加入 spring-boot-starter-jdbc、MySQL 驱动 | bootJar 编译 |
| src/main/resources/application.properties | MySQL 环境变量、初始化 SQL、会话配置；关闭元数据缓存确保编号高水位 | 启动日志、重启数据保留 |
| src/main/resources/db/schema.sql | 十二表、外键、唯一与 CHECK；密码哈希、订单生成列 | verification.sql |
| repository/MarketRepository.java | 内存存储改 JDBC；事务行锁、差异提交、Operation；元数据分配商品编号 | 回滚、并发抢单、持久化测试 |
| repository/ProductRepository.java | 六方法、工作副本重载、图片维护、历史检查 | Repository 和 CRUD 测试 |
| model/Product.java | 手写 Builder，每次 build 独立对象 | Builder 测试 |
| service/CatalogService.java | 使用商品 Repository；scope、删除保护、Builder 发布 | 查询、CRUD、权限与历史测试 |

| controller/AuthController.java | 注册、登录、会话信息、退出 | 浏览器与 API 测试 |

上述 controller/service/model/repository/security 缩写目录位于 `src/main/java/com/example/demo/`，static 位于 `src/main/resources/`。

## 升级步骤

1. 停止旧进程，保留原压缩包；新包解压到新目录。
2. 创建独立 MySQL 库，填写环境配置。
3. 用新 JAR 或 IDEA 主类运行；Ctrl+F5 刷新浏览器，重新登录。
4. 发布测试商品→查询→编辑→删除→再查 404；验证历史商品不可删除。
5. 演示审核、下单、交付、评价、退款、举报与重启保留。

旧版内存中临时发布/聊天/订单不会自动迁移。原有 demo-seed.json 只作为首次可选种子；没有声称恢复旧进程中已丢失的临时记录。
