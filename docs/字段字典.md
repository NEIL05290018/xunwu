# 十二表字段字典

字段名与 Java 模型保持 snake_case；具体 SQL 类型、长度和约束以 `database/schema.sql` 为准。

## admins

| 字段 | SQL 类型 |
|---|---|
| admin_id | INT |
| login_name | VARCHAR(255) |
| password_hash | VARCHAR(255) |
